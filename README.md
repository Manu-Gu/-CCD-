# CCD 分度板十字线读数系统

用于杨氏模量测量中光杠杆法分度板的实时示数识别。CCD 相机固定，画面中央有十字线，标尺随加载移动，程序自动跟踪十字线对应的刻度值。

## 环境

```bash
pip install -r requirements.txt
```

Python >= 3.10，依赖 opencv-python、numpy、scipy。

## 使用

```bash
python live_stream.py                  # 自动选相机
python live_stream.py --camera 0       # 指定相机
python live_stream.py --list           # 列出所有相机
```

## 操作

### 标定

| 步骤 | 操作 | 说明 |
|------|------|------|
| ① | 对准标尺，按 **Enter** | 冻结当前帧 |
| ② | **左键** 点击刻度线 | 终端输入该线数值（如 0、5、10） |
| ③ | 至少标 2 条后 **Enter** | 确认，进入实时读数 |

### 按键一览

| 按键 | 功能 |
|------|------|
| `Enter` | 锁帧标定 / 确认标定 / 重新标定 |
| `Tab` | 切换相机 |
| `空格` | 记录当前读数 |
| `ESC` | 标定中取消，退回预览 |
| `q` | 退出 |
| 左键 | 标定模式下点击刻线 |
| 右键 | 撤销上一个标记 |

### 退出时

自动打印所有记录数据：

```
  No.    Timestamp            Reading (mm)
  -----------------------------------------
  1          0.00 s                   0.000
  2          5.12 s                   0.435
  3         10.30 s                   0.890
```

## 原理

1. **标定**：点击 N 条刻度线并输入数值，线性回归得 `value = a * pixel + b`
2. **跟踪**：每帧做垂直投影，与标定帧投影信号做归一化互相关，算出标尺像素偏移
3. **读数**：十字线坐标减偏移量，代入标定映射得刻度值
